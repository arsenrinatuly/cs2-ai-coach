# ADR-001 — Modular monolith

**Status** Accepted

Keep the backend in one Python project with separate modules for parser
integration, domain models, persistence, analytics, HTTP, and coaching. The CLI
and HTTP entry points share domain contracts. The future worker can run as a
separate process from the same backend image.

This keeps contracts and tests in one place and limits deployments and data
ownership boundaries during the MVP. Awpy-specific DataFrames stay in the
parser adapter. Persistence and user interfaces use validated records.

Extract a separate service only when workload isolation, independent scaling,
or ownership requirements justify an additional deployment boundary.
